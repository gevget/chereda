# Chereda — состояние после переустановки Windows

Дата проверки: 16 ноября 2026 года. Рабочая папка: `E:\codex\chereda`.

## Продукт и точка продолжения

Проект — локальное investor demo визуального поиска в event-индустрии. Основной путь: лента/рилс → проект → credits команды → профиль → услуга → локальная заявка. PRO — режим каталога, Project и Case — одна сущность. Backend, production-auth, платежи и настоящая отправка сообщений не подключены.

Реализованы лента, поиск, PRO и категорийные фильтры, профили, проекты, рейтинги, коллекции, подписки, сравнение конкретных услуг, журнал заявок, настройки, информационные страницы и demo hub. Дополнительные локальные сценарии: brief, комнаты проектов, подбор команды, сравнение предложений, подбор площадки, production board, credits passport, международный preview, партнёрские страницы и Radar.

Раздел событий содержит афишу, категории, календарные периоды, сеансы, локальные регистрации, сохранение и создание локальных черновиков. Последние локальные доработки связывают события с проектами и профилями, добавляют отзывы завершённых сеансов и сохранение контекста возврата.

План продолжения и журнал последней сессии находятся в `chereda-spec/10_CHEREDA_1_0_ROADMAP.md`. Версия 1.0 ещё требует подробной продуктовой сверки внутренних разделов, визуальной и доступной полировки и итоговой сквозной приёмки. Считать её полностью принятой по одному прежнему QA нельзя.

- Файл архитектуры с суффиксом `(1)` — более ранняя копия. Основным остаётся файл без суффикса.
- Есть несогласованность правил иконок: дизайн-система требует Phosphor, а поздний QA и код содержат локальные Lucide SVG. Перед дальнейшим изменением UI нужно учитывать историю исключения и согласовать документацию.
- GitHub Actions настроен на static export и GitHub Pages при push в `main`; конфигурация также предусматривает обычный локальный Next server. Успешность новой публикации ещё не проверялась.
