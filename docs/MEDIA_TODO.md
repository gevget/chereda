# Media shot list

Локальные SVG сейчас демонстрационные и индивидуальны для каждого кадра; они не являются stock-фотографиями или портфолио вымышленных специалистов. Для публичной визуальной версии заменить их на разрешённые локальные файлы с заполненными source URL, author, license URL и alt в manifest.

Запросы для 10 hero-проектов: `editorial wedding venue botanical long table`, `neon event brand launch`, `intimate dinner waterfront`, `conference stage audience`, `industrial team building`, `awards ceremony lighting`, `desert botanical dinner`, `classic wedding editorial`, `live concert audience`, `immersive kids event`. Для «Белого сада» дополнительно: `wedding hair preparation hands`, `bridal makeup preparation`, `event manicure detail`, `florist table installation`, `catering plated dinner`.

Для каждого hero-проекта: общий план, пространство, 2 детали декора, подготовка, программа, кейтеринг, backstage. Источники: только бесплатные Unsplash, Pexels или Pixabay после проверки лицензии конкретного материала. Один файл не использовать в разных проектах.
